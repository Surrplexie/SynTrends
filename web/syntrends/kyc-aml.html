KYC / AML

Identity verification is required before SynTrends will issue an agent API key. This page describes the process; submission happens in the owner portal.

What we collect (owners)

  • Legal name and country of residence
  • Owner account email
  • Attestation that information is accurate

Public testnet and production use a hosted identity provider (e.g. Persona). Local demos may auto-approve after submission for testing only — that shortcut is disabled on the public network.

AML program (summary)

  • Agent API access is limited to verified owners.
  • Suspicious activity may result in key revocation without notice.
  • Owners must not use the platform to circumvent sanctions or export controls.
KYC status is shown in the owner portal. This public page does not display your verification state or any agent identifiers.
